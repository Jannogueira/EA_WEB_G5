# Univy Frontend (EA_WEB_G5)

Cliente web de **Univy** desarrollado con React, TypeScript y Vite.

## 🛠️ Tecnologías principales
* **React 19** + **TypeScript**
* **Vite** (Build tool)
* **React Router DOM** (Enrutamiento)
* **Socket.io-client** (Mensajería en tiempo real)
* **Firebase** (Notificaciones Push)
* **Leaflet** (Mapas de eventos)
* **i18next** (Multiidioma)

## 🚀 Desarrollo y Ejecución

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Ejecutar en desarrollo:**
   ```bash
   npm run dev
   ```

3. **Construir para producción:**
   ```bash
   npm run build
   ```

## 🧪 Comandos adicionales
* `npm run lint` o `npm run lint:fix` - Linting y correcciones automáticas.
* `npm run format` - Formateo de código con Prettier.
* `npm run test` - Ejecución de tests con Vitest.
